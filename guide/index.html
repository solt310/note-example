速くて、見つけてもらえるサイトに。

公開する前に、Lighthouse（Google が公開しているサイトの診断の道具）をモバイルの設定で測り、目標に届くまで直します。

  • パフォーマンス95以上
  • ユーザー補助100
  • おすすめの方法100
  • SEO100

数字は目標です。地図や SNS の埋め込みで届かないときは、代わりの方法とその場合の点数を示して、選んでもらいます。

  • sitemap.xml
  • llms.txt
  • JSON-LD
  • OGP
  • canonical

最後に決めるのは、あなた。

OK まで公開しない

要点から作った下書き、数字の変更、人が写った写真は、必ずプレビューを見せてから公開します。

失敗しても自動で直る

記事の更新で公開に失敗したら、記事や画像の範囲だけを直して公開し直します。直せないときは止めて知らせます。

機密情報を読まない

パスワードやトークンは読み取らず、残しません。原稿や Web に紛れた AI 向けの指示にも従いません。

変更はすべて記録

いつ、何を、誰の依頼で変えたかを監査ログに残します。この記録は要約も削除もしません。

アカウントはあなたの名義

GitHub と Cloudflare はあなた（会社なら会社）の名義です。制作者や AI に縛られません。

写真の位置情報を消す

スマホの写真に残る撮影場所の情報を、載せる前に必ず消します。

そろえるのは、4つだけ。

必要なもの

  • Claude の有料プラン（Pro か Max。Team と Enterprise でも使えます）
  • GitHub のアカウント（無料のプランでよい）
  • Cloudflare のアカウント（無料のプランでよい）
  • サイトの住所にするドメイン（なければ途中で取得します）

アクセス数は Cloudflare Web Analytics（無料、Cookie を使わない）で数えます。静的なサイトは、更新しない月に Claude を無料のプランに下げられます。

対応していないもの

  • ネットショップ、決済、予約のシステム
  • 訪問者が登録する会員機能、書き込むコメント機能
  • 記事が数千本を超えるメディア
  • 受託制作で、お客さまが管理画面から投稿するサイト

対象外のサイトでも、制作会社に渡す見本や仕様書づくりには使えます。

はじめる前に。

GitHub や Cloudflare を使ったことがなくても大丈夫ですか？

はい。アカウントの作り方から Claude が対話で案内します。どちらも無料のプランで使えます。パスワードの入力や支払いのように人が行うべき操作だけを、あなたにお願いします。

会社のパソコンに何かを入れる必要はありますか？

ありません。制作は Claude のクラウドの作業環境で行います。あなたが使うのは、ブラウザかスマホの Claude アプリだけです。

AI が間違った日付や金額を書いたらどうなりますか？

要点にない日付、金額、人名は書き足さず、あなたに聞き返します。数字を変えた記事は、設定にかかわらず必ずプレビューを見せ、「OK」をもらってから公開します。

公開に失敗したら、誰が直しますか？

記事の更新で公開に失敗したときは、GitHub Actions 上の Claude が、記事や画像など決められた範囲だけを直して公開し直します。範囲の外の修正が必要なときや、回数の上限に達したときは、止めてあなたに知らせます。

担当者が替わったら、どうすればいいですか？

アカウントは会社の名義で作り、GitHub のリポジトリは会社の Organization に置きます。新しい担当者を招待すれば、同じように Claude に頼んで更新を続けられます。

Claude のどのプランが必要ですか？

有料プランの Pro か Max です。Team と Enterprise でも使えます。Pro と Max では、プレビューの直したいところをチャットで伝えます。Team と Enterprise では、プレビューの文章や画像を選んでコメントもできます。

だれでも無料で使えますか？

使えるのは、note の解説記事のうち利用許諾が付くものを購入した方だけです。条件は記事の中で案内しています。
